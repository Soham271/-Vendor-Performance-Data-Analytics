# 📊 Vendor Performance Data Analytics

## 🚀 Project Overview

This project focuses on **Vendor Performance Analytics** using Python, SQL, Power BI, and Statistical Analysis techniques to derive actionable business insights from procurement, inventory, and sales data.

The objective of this project is to:

* Analyze vendor and brand performance
* Identify top-performing and low-performing vendors
* Understand procurement efficiency
* Detect inventory risks and unsold capital
* Perform statistical analysis using confidence intervals and hypothesis testing
* Build interactive dashboards in Power BI

# 🧪 Statistical Analysis

## Null Hypothesis (U0)

There is no significant difference between the profit margins of top-performing and low-performing vendors.

## Alternative Hypothesis (U1)

There is a significant difference between the profit margins of top-performing and low-performing vendors.

### Techniques Used:

* 95% Confidence Interval
* Independent Two-Sample T-Test
